Who connects to whom, and who would feel it if one node fell?

A browser-based map of a bipartite network: nodes of two types and the links between them. Run the layout live, drag a node and watch its neighbours respond.

How it works

Everything runs in your browser. cosmos.gl computes the force layout on the GPU through WebGL and draws the graph. There is no server.

The data is anonymised bipartite-network connectivity with artificial link weights. The data source is not disclosed. Identifiers are replaced, and link weights are sampled from a fitted distribution rather than taken from the source. Any propagation model shown later is stylised and illustrative only.

  • Requires a browser with WebGL. WebGPU is not needed.
