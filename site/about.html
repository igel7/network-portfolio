How this was built

cosmos.gl (MIT) provides the GPU force layout and rendering in the browser. The data preparation, modelling, analysis design and the interface are my own work.

The network is anonymised bipartite-network connectivity with artificial link weights. The data source is not disclosed. Identifiers are replaced and weights are sampled from a fitted distribution; they are not the source values. Planned propagation and group-detection features will be stylised models, illustrative only.
